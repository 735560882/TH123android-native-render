# TH123 Android Native Render

东方非想天则（TH12.3）的 Android 运行与渲染替代层。

> [!IMPORTANT]
> 本项目**不包含**任何东方系列游戏的可执行文件、图片、音乐、音效、字体或其他原作资源。使用前必须自行准备合法持有的游戏副本。

## 项目状态

- 渲染层：自研的 OpenGL ES 3.0 后端，通过 EGL 离屏渲染输出，已与 Windows 图形 API 解耦。
- 回放管线：支持录制（`.thrr`）与独立播放器，已交叉编译为 ARM64 并在真机上验证。
- 逻辑层：计划通过 Wine 与 Box64 运行原版游戏，并以自研 `d3d9` 替代实现接管图形输出。

这些内容仍在开发中，尚不能直接游玩。

## 使用前提

使用本项目前，你需要：

- 合法持有游戏副本，例如通过正规渠道购买的东方非想天则；
- 自行将游戏文件放置在本地目录中，启动器只会读取你指定的路径；
- 自行确认所在地区的法律允许你进行此类使用。

本项目不提供、不推荐、也不链接任何游戏文件的下载来源。

## 快速开始

> **当前状态**：仓库尚未包含可编译或可安装的代码，下面的步骤是计划中的使用流程，代码迁入后会据此更新为实际命令。

### 1. 准备游戏副本

自行准备合法持有的东方非想天则（TH12.3）游戏文件，放在本地一个你熟悉的目录中。本项目不会提供或下载这些文件。

### 2. 准备运行环境

- 一台 ARM64 Android 设备（计划支持的最低系统版本待定）；
- 按 [THIRD_PARTY.md](THIRD_PARTY.md) 中列出的组件版本，准备 Wine、Box64 及相关运行库。

### 3. 安装并指定游戏目录

安装本项目的 APK 后，首次启动时选择你在第 1 步中准备的游戏目录。启动器只读取该目录，不会复制或上传其中的文件。

### 4. 运行与回放

- 启动器会通过 Wine + Box64 运行原版游戏逻辑，并由本项目的 `d3d9` 替代层输出到 OpenGL ES；
- 录像文件（`.thrr`）可以用独立的回放播放器打开，用于验证渲染输出。

### 常见问题

- **找不到游戏文件**：确认目录中包含原版的可执行文件，并检查路径权限。
- **画面异常**：请在 issue 中附上设备型号、系统版本和你使用的组件版本。
